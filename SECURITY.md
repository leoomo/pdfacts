# Reporting a security problem

Report it through GitHub's private vulnerability reporting, on this
repository's [Security tab](https://github.com/leoomo/pdfacts/security).
Please do not open a public issue for it.

Say what you found with:

- the output of `pdfacts.engine_info()` — the engine versions the facts
  depend on;
- the file that shows the problem, or one built to show it;
- what happens, and what you expected instead.
